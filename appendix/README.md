# Appendix

This appendix provides reference material for the SSI documentation: a glossary of all terms used throughout the documentation, and an index of all referenced standards with links.

## Contents

| File | Topic |
|------|-------|
| [glossary.md](./glossary.md) | Alphabetical glossary of all SSI terms, acronyms, and concepts |
| [standards-index.md](./standards-index.md) | All referenced standards, specifications, and RFCs with links and descriptions |

## Usage

- The **glossary** defines terms on first encounter. When a term appears in the documentation without explanation, its definition can be found here.
- The **standards index** provides authoritative links to every specification referenced in the documentation. When the documentation cites a standard (e.g., "RFC 9449"), the standards index provides the full title, link, and a brief description of its relevance.
